# ADAS-Object-Detection-Comparative-Benchmark
Source code and experimental configuration for the comparative evaluation of YOLOv8, YOLOv10, Faster R-CNN, ResNet-101, and DETR on the MAN TruckScenes camera dataset.

This repository contains the representative training and evaluation code used in the study “Deep Learning based Object Detection Techniques for Autonomous Commercial Driving in Advanced Driver Assistance Systems: Comparative Analysis.” The study presents an empirical comparison of five object-detection approaches—YOLOv8, YOLOv10, Faster R-CNN, a ResNet-101-based detection framework, and DETR—using the MAN TruckScenes camera dataset under a common comparative evaluation setting. The repository provides representative implementation snippets, training configurations, and evaluation procedures to support transparency and reproducibility of the reported experiments. The MAN TruckScenes dataset, proprietary class annotations, trained model weights, and restricted third-party implementations are not redistributed in this repository because of data-sharing and licensing restrictions. Users should provide their own authorized dataset access and modify the documented paths accordingly.
